1

Collect

Draw an area on the map. The app downloads a 10-band Sentinel-1/2 GeoTIFF for February 2025 and takes a high-resolution screenshot of the same area.

 2

Label

Draw water, tree, crop, building and other polygons on the screenshot. You get masks lined up with the GeoTIFF, ready for training.

 3

Monitor

Run the 10-band U-Net on any area to get a land-cover map, tree cover % and an estimated tree count (big and small) calibrated on the Gazipur hand counts.

Data in this project

  • 50 human-labelled areas in data/labelled/: each has a 10-band GeoTIFF, a label mask and a screenshot. These train the land-cover model.
  • 300 hand-counted Gazipur squares in data/gazipur/: small, big and total trees and tree cover % per 100 m square. These calibrate the tree counter.

Retrain after adding areas: python ai/train_segmentation.py then python ai/train_counter.py.
